# Consignes de travail

## Méthode : Figma d'abord, code ensuite
- Toute interface (page, écran, composant) est d'abord maquettée dans Figma.
- Aucun code d'interface n'est écrit avant que la maquette Figma correspondante existe et soit validée par l'utilisateur.
- Le code est ensuite produit à partir de la maquette (Figma MCP, `get_design_context`), en réutilisant le design system Figma.

## Communication
- Commencer chaque réponse par un résumé en une ligne de la demande (« **Demande :** … »).
- Réponses courtes, en français, limitées à l'essentiel.
