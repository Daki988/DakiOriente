# Carrousel « Choisissez un emoji et suivez la ligne »

6 slides Instagram 1080 × 1350 (4:5). Les slides 1 à 5 sont un seul panorama : les lignes passent d'une slide à l'autre sans coupure.

- 🐘 → Un site web qui vend · 🥭 → Votre fiche Google · 🌴 → Des réseaux qui convertissent · 🐢 → Un assistant IA sur WhatsApp
- Régénérer : `python3 lignes.py && node render.js` (trajets et textes dans `lignes.py`, mise en page dans `modele.html`).
