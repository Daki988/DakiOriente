Régénérer une vidéo : `node render.js <page.html> <sortie.mp4> <durée>` (les pages HTML contiennent toute l'animation).
La mascotte (`mascotte/`) a été générée par IA ; « Maison Okoumé » est un site fictif d'exemple.
