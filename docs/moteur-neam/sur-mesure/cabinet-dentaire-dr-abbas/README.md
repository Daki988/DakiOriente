# Cabinet dentaire Dr Abbas : site sur mesure

Base : le site du cabinet dentaire ACAE Sourire (mêmes classes), avec ses propres couleurs (bleu nuit, ambre) et contenus.

- `data.js` : 7 soins, parcours, FAQ, équipe (prénoms fictifs), affluence indicative par heure.
- `build.js` : 8 pages, dont **Sans rendez-vous** (ouvert ou fermé maintenant, affluence heure par heure selon le jour, meilleur moment pour passer).
- `abbas.css`, `abbas.js` : style et interactions.
