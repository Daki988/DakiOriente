# Socle commun des sites d'hôtel

`hotel-kit.js` construit 8 pages à partir des données d'un hôtel (`build(H, dir)`) : accueil avec recherche de dates, chambres, réservation
(prix week-end, remises long séjour, options par nuit / personne / séjour, alerte de capacité, commande WhatsApp), restaurant, page propre à l'hôtel,
l'hôtel (histoire, équipements, FAQ), galerie, contact. `hotel.css` donne la mise en page ; chaque hôtel apporte son `theme.css` (couleurs, polices).
Utilisé par `hotel-heliconia/` et `hotel-le-jomonia/`.
