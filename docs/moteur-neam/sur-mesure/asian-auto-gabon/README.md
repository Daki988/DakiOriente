# Asian Auto Gabon : site sur mesure

Vendeur de pièces détachées : le site mise sur la **demande de pièce par numéro de châssis** (VIN).

- `data.js` : contenus (marques servies en texte seul, 6 familles de pièces, lubrifiants sans marque, avis).
- `build.js` : génère 7 pages dans `neam-moteur/sites/asian-auto-gabon/` (`node build.js`) : accueil (recherche rapide), catalogue (onglets), demande de pièce, lubrifiants, l'entreprise, galerie, contact.
- `asian.css`, `asian.js` : style (noir du logo, rouge) et interactions (contrôle du VIN : 17 caractères sans I, O, Q ; liste de pièces avec quantités ; récapitulatif ; envoi WhatsApp ou e-mail).

Infos réelles : ex-NPS Gabon devenu Asian Auto Motors (2021), distributeur de pièces d'origine pour véhicules japonais et coréens, lubrifiants, véhicules ; av. Georges Damas Aleka, Glass, BP 9222 Libreville ; 011 72 53 72, 062 12 37 37 ; magasin@asianauto-gabon.com. Logo réel redessiné.
