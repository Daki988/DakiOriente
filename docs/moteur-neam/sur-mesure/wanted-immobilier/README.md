# Wanted Immobilier : site sur mesure

- `data.js` : 10 biens d'exemple (location et vente), 8 quartiers de Port-Gentil, 5 métiers, dossier locataire, avis.
- `build.js` : 7 pages (accueil avec recherche, nos biens, propriétaires, bon à savoir, l'agence, galerie, contact).
- `wanted.css`, `wanted.js` : style (turquoise du logo, ardoise, sable) et interactions :
  recherche filtrable (louer/acheter, type, quartier, chambres, budget, meublé, tri), fiche du bien avec photos et demande de visite WhatsApp,
  alerte si aucun bien ne correspond, simulateur de revenus pour les propriétaires, liste du dossier locataire gardée sur l'appareil.

Infos réelles : « La clé de votre logement » ; location, gestion, vente, syndic, agencement ; Carrefour des Douanes, BP 1503 Port-Gentil ; 066 62 25 00 ; Virginie LEPOIVRE. Logo réel (clé et ville) redessiné.
