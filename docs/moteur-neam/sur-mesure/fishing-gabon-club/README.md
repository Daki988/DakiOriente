# Fishing Gabon Club : site sur mesure

Guide de pêche sportive : le site mise sur la **réservation de sortie** et le **calendrier des espèces**.

- `data.js` : contenus (5 formules, 7 espèces avec saisons mois par mois, avis).
- `build.js` : génère 7 pages dans `neam-moteur/sites/fishing-gabon-club/` (`node build.js`) : accueil (« ce qui mord ce mois-ci »), sorties, espèces et saisons (choix du mois + calendrier), réserver, le club, galerie, contact.
- `fishing.css`, `fishing.js` : style (bleu océan, orange, sable) et interactions (réservation 48 h à l'avance minimum, nombre de personnes limité par formule, avis de saison selon la date et l'espèce, tarif par personne, envoi WhatsApp).
