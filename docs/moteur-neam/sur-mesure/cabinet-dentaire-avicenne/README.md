# Cabinet dentaire Avicenne : site sur mesure

Même architecture que les sites CIMEL et Saint Raphaël (soins, avant/après, rendez-vous avec créneaux), adaptée au dentaire.

- `data.js` : contenus (7 soins, parcours, conseils, assurances, équipe, avis, FAQ).
- `build.js` : génère les pages dans `neam-moteur/sites/cabinet-dentaire-avicenne/` (`node build.js`).
- `avicenne.css`, `avicenne.js` : style et interactions.
