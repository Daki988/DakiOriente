# Bijouterie de l'Écrin : site sur mesure

Mise en page reprise de Delicatess (mêmes classes CSS), avec ses propres couleurs (bordeaux, or, crème) et contenus.

- `data.js` : contenus (12 pièces, 5 rayons, services de l'atelier, avis).
- `build.js` : génère les pages dans `neam-moteur/sites/bijouterie-de-l-ecrin/` (`node build.js`).
- `ecrin.css`, `ecrin.js` : style et interactions (sélection gardée sur l'appareil et réservation d'essai sur WhatsApp, filtres, guide des tailles de bague, demande à l'atelier).
