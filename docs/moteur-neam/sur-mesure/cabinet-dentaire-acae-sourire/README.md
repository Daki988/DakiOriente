# Cabinet dentaire ACAE Sourire : site sur mesure

Base : le site du cabinet dentaire Avicenne (mêmes classes), avec ses propres couleurs (indigo, corail) et contenus.

- `data.js` : 7 soins, parcours, FAQ, équipe (prénoms fictifs) et 7 situations d'urgence.
- `build.js` : 8 pages, dont **Urgence dentaire : que faire ?** (choix de la situation, délai conseillé, gestes en attendant, appel ou WhatsApp).
- `acae.css`, `acae.js` : style et interactions.
