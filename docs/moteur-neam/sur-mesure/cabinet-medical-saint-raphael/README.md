# Cabinet médical Saint Raphaël : site sur mesure

Même architecture que le site CIMEL (consultations, préparation, rendez-vous avec créneaux), adaptée à l'angiologie et à la cardiologie.

- `data.js` : contenus (6 consultations, examens et traitements, parcours, conseils, équipe, avis, FAQ).
- `build.js` : génère les pages dans `neam-moteur/sites/cabinet-medical-saint-raphael/` (`node build.js`).
- `raphael.css`, `raphael.js` : style et interactions.
