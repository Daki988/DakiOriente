# Guide d'administration — Jackboy

L'administration permet de modifier le site **sans développeur**. Elle fonctionne sur téléphone et ordinateur.

## Se connecter
1. Ouvrir **https://VOTRE-DOMAINE/keystatic**.
2. Cliquer sur « Se connecter avec GitHub » (compte fourni par NEAM lors de la formation).

## Modifier un prix ou un produit
1. Menu de gauche → **Menu & prix**.
2. Ouvrir la catégorie (ex. *Paninis*), puis le produit.
3. Modifier le **prix en FCFA** (chiffres seulement, ex. `3500`). Laisser `0` affiche « Prix à confirmer ».
4. Cocher/décocher :
   - **Disponible** — décocher affiche « Indisponible » (le produit reste visible, grisé) ;
   - **Produit signature** — le met en avant sur l'accueil ;
   - **Nouveau** — ajoute un badge.
5. Cliquer **Enregistrer** (en haut à droite). Le site est à jour en ~1 minute.

Ajouter un produit : bouton **+ Ajouter** sous la liste. Réordonner : glisser-déposer.

## Ajouter un événement
**Événements** → **+ Ajouter** → titre, date au format `2026-10-31`, heure `22:00`, DJ, description, affiche (photo).
Les événements passés disparaissent automatiquement du site.

## Photos de la galerie
**Galerie & équipe** → **+ Ajouter** → choisir la photo, écrire une **description** (pour les malvoyants et Google), choisir l'ambiance.
Conseil : photos horizontales ou verticales de 2000 px max ; le site les optimise automatiquement.

## Horaires et téléphones
**Infos pratiques** :
- **Téléphones** : le **premier** est le contact principal (bouton « Appeler »). Numéro au format `+24177000000`.
- **Horaires** : une ligne par jour. Une fermeture à `06:00` signifie 6 h le lendemain matin. Cocher « Fermé ce jour » si besoin.
- L'indicateur « Ouvert / Fermé » du site se calcule automatiquement.

## Avant la mise en ligne
Dans **Infos pratiques**, décocher **Mode démonstration** une fois toutes les vraies informations saisies.

## En cas de problème
Chaque modification est historisée : NEAM peut revenir à n'importe quelle version précédente.
