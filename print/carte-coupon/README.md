# Carte découpée « téléphone » NEAM

Inspirée des cartes-coupons découpées en forme de produit : un smartphone en paysage (écran : l'accueil du site NEAM) « emballé » par une étiquette.

- Format 100 × 55 mm, 6 cartes par feuille A4 paysage : `NEAM_carte-telephone_A4.pdf`. Découper sur les pointillés (papier 300 g conseillé, imprimer à 100 %, sans ajustement à la page).
- Message : NEAM Digital Score gratuit, QR code vers https://www.neamindustry.com/digital-score.html.
- Régénérer : `node ecran.js` (capture de l'écran du site) puis `node render.js`.
