# Carte de visite — Daril OYE MBA

Format 85 × 55 mm, recto verso, 3 mm de fond perdu (PDF 91 × 61 mm), zone sûre à 4 mm du trait de coupe.

- `carte-visite.html` : source (polices et logos du dépôt, QR code vers www.neamindustry.com dans `qr-site.svg`).
- `node render.js` : régénère `NEAM_Carte-visite_Daril-OYE-MBA.pdf` (2 pages, à donner à l'imprimeur) et les aperçus `carte-recto.png` / `carte-verso.png` (600 dpi, format fini).
