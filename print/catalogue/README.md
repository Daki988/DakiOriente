# Catalogue NEAM 2026 – 2027

PDF A4 de 20 pages : `NEAM_Catalogue_2026-2027.pdf`, prêt à imprimer ou à partager.

- `catalogue.py` génère `catalogue.html` (contenus : Company Blueprint 2027, présentation NEAM × KANIE 30/30, site).
- `catalogue.css` : mise en page (même charte que le site), `fonts/` : polices intégrées.
- `render.js` : contrôle des débordements, aperçus PNG et export PDF avec Playwright (Chromium).

À compléter avant diffusion : le nom du fondateur (`FONDATEUR_NOM` dans `catalogue.py`) et la validation du « Mot du fondateur ».
Ce dossier n'est pas destiné à l'hébergement : il n'est pas inclus dans l'archive du site.
